📋 8人制 3-3-1 とは

8人制サッカーは通常 GK + フィールド7人 で行われます。3-3-1はバランス型の定番フォーメーションで、Jリーグの4-2-3-1や3-4-2-1の考え方を8人制に縮小した形と言えます。


川崎フロンターレの「位置取りサッカー」、横浜F・マリノスの「ハイプレス＋サイド攻撃」、ヴィッセル神戸の「3バック＋インサイドハーフ」——これら強豪の共通点は「幅を使い、中央を人数で支配し、前線1人に決定力を集中させる」ことです。8人制3-3-1でも同じ原則が使えます。

8人制の特徴

  • ピッチが狭い → 1タッチ・2タッチの速いパスが効く
  • 人数が少ない → 1人の空きが大きなチャンスになる
  • 全員が攻撃にも守備にも関与する「トータルサッカー」的要素が強い
  • サイドの使い方が勝敗を左右する

3-3-1の強み

  • 中盤3人で人数優位を作りやすい
  • 守備時は5-2-0に変化し、ブロックが組みやすい
  • サイドバック（WB）が攻撃の幅を提供
  • FW1人に集中供給 → 決定力のある選手を活かせる

⚔️ 攻め方 — Jリーグ強豪の考え方

基本原則：「幅 → 深さ → 決定打」

Jリーグ上位チームの攻撃は大きく3フェーズに分かれます。8人制でも同じ流れを意識しましょう。

  1. ビルドアップ（自陣〜中盤） — GK/CBからサイドまたはCMへ。相手プレスを避けつつ、中盤3人で人数優位を作る
  2. プログレス（中盤〜前線） — サイドへの展開、CMの前進、STの引きつけで相手DFラインを崩す
  3. フィニッシュ（最終三分の一） — クロス、スルーパス、シュート。ゴール前に人数を集中させる
川崎型

位置取りサッカー（Possession）

  • ボールを持つ選手の近くに常に2〜3人がサポート
  • 三角形のパスコースを常に確保
  • 相手を引きつけてから弱いサイドへ素早く展開
  • 焦らず、相手の形が崩れるまで保持
8人制での使い方： CMがボールを持つ → LM/RMが左右に広がる → CB/LB/RBが後方サポート → 相手MFが寄せたら反対サイドへワンタッチで展開
マリノス型

ハイプレス＋速攻（Transition）

  • 相手のビルドアップを前線から妨害
  • 奪取後は3秒以内に前線へ送る
  • ST＋LM/RMの3人でゴール前に人数を作る
  • サイドから中央へのカットイン、またはクロス
8人制での使い方： 相手CBの横パスをST+CMがカット → 奪取即STへ → LM/RMが両サイドに走り込み → 2対1や1対1でゴール前
神戸型

3バック＋インサイドハーフ

  • LM/RMがインサイドに入り、CMと中央で人数を作る
  • LB/RBが幅を取りに上がる（WB化）
  • 中央3人（CM+LM+RM）で相手MFを上回る
  • STは相手CB2人を引きつけ、インサイドから供給
8人制での使い方： LM/RMが中央寄りに入る → LB/RBが高い位置で幅 → CMがフリーのスペースで受ける → STへのスルーパス or シュート

攻撃時のポジション変化（3-3-1 → 2-3-2-1）

ボールを持って前進するとき、フォーメーションは流動的に変化します。

  • LB/RB → ハイポジションで幅を提供（オーバーラップ）
  • LM/RM → インサイドに入るか、サイドライン際で1vs1
  • CM → ペナルティエリア前（ハーフスペース）で受ける
  • CB → 後方でカバー（カウンター対策）
  • ST → CBラインの裏 or 前で支点

🛡️ 守り方 — 組織的ディフェンス

守備の基本：5-2-0 ミッドブロック

8人制3-3-1の守備形は 5-2-0（DF3 + MF2、FW1は相手CBをマーク）が基本です。Jリーグでも主流の「ミッドブロック」を採用します。

守備原則 ①：ブロックの厚み

  • DFラインとMFラインの距離は 10〜15m を目安
  • 縦のラインを揃え、スルーパスの隙をなくす
  • CBは最後方に残り、LB/RBはサイドをカバー
  • 相手ST1人に対してCB+CMで2対1を作る

守備原則 ②：プレスのタイミング

  • 高いプレス： 相手GK/CBの受けた瞬間にST+CMが寄せる（マリノス型）
  • ミッドプレス： 中盤で待ち、横パスを誘ってから奪う（川崎型）
  • ローブロック： ペナルティエリア前で人数を固める（神戸型）

守備原則 ③：奪取後の動き

  • 奪ったら即座に前を向く（ターンオーバー）
  • ST+LM/RMが前線に走り込み開始
  • CMが最初のパスを出す「出口」になる
  • カウンターは3秒ルール：3秒以内に前線へ

守備原則 ④：セットプレー守備

  • FK：壁3人＋残り4人でゾーン（8人制は人数が少ないため壁を厚く）
  • CK：ニアポスト1人＋ファー2人＋残りはマーク
  • スローイン：ニア1人＋他はライン維持
  • ゴールキック：DFラインを上げてコンパクトに

🎯 実践攻撃パターン（5選）

実際の試合で使える具体的な攻撃の流れです。練習で繰り返し、試合で使えるようにしましょう。

パターン1サイドオーバーラップ

サイド展開 → オーバーラップ → クロス

参考： 横浜F・マリノスの定番サイド攻撃

  1. CMがボールを持ち、左サイドのLMへパス（相手MFの注意を左に引く）
  2. LMがサイドライン際でボールを保持。同時にLBがオーバーラップで前に上がる
  3. LMはLBへパス、または1vs1で相手DFを抜く
  4. LB（またはLM）がゴール前へクロス。STがニアポスト、CMがファーポストへ走り込む
ポイント： LBのオーバーラップが鍵。LMがボールを持つ間にLBが走り込むタイミングを合わせる。RM/CMはファーポストカバー。
パターン2中央突破

ST引きつけ → CM前進 → スルーパス

参考： 川崎フロンターレの中央突破

  1. CBからCMへパス。STは下がって相手CBを引きつける（ドロップ）
  2. STが相手CB2人の注意を引いた隙に、CMがドリブルまたはパスで前進
  3. STが一気に裏へ走り込み（オフサイドラインの裏）
  4. CMからSTへスルーパス → 1対1 with GK → シュート
ポイント： STの「下がってから走る」動きが最重要。相手CBを1人引きつければ、CM前進のスペースが生まれる。
パターン3カウンター

奪取 → 即展開 → 3対2速攻

参考： 横浜F・マリノスの速攻（アンチ・プレス）

  1. 中盤でCMまたはLM/RMが相手からボール奪取
  2. 奪取した選手は即座に前を向く（ターンオーバー）。3秒以内にパス
  3. ST＋LM＋RMの3人が前線へ走り込み（トランジション）
  4. 相手DFは2人しか戻れていない → 3対2の数的優位
  5. ボール保持者がSTへ送る → STがLM or RMへ横パス → ゴール前で2対1
ポイント： 「奪った瞬間」が勝負。ためらうと相手が戻る。STは中央、LM/RMは両サイドに広がる。
パターン4インサイドカット

LM/RMインサイド → ハーフスペース → シュート

参考： ヴィッセル神戸のインサイドハーフ戦術

  1. LM/RMがサイドではなく中央寄り（ハーフスペース）でボールを受ける
  2. LB/RBがサイドライン際まで上がり、幅を提供
  3. LM/RMがインサイドにカットし、DFラインの間を突破
  4. STが相手CBを引きつけ、LM/RMがフットワークで1vs1
  5. ペナルティエリア前でシュート or STへのパス
ポイント： 8人制はゴールまでの距離が短い。ハーフスペースからのシュートは非常に有効。LM/RMの技術力が問われる。
パターン5スイッチ

密集 → 反対サイドへスイッチ → 1vs1

参考： 川崎フロンターレのサイドチェンジ

  1. 左サイド（LM+LB）にボールを集中させ、相手MF/DFを左に引き寄せる
  2. CMまたはCBからロングパスで右サイド（RM）へ一気にスイッチ
  3. RMが相手DF1人との1vs1局面を作る
  4. RMがドリブルで突破 → ゴール前へクロス or シュート
  5. ST＋CMがゴール前で走り込み
ポイント： 8人制はピッチが狭いので、スイッチのタイミングが早いほど効果的。CBから直接RMへ送る勇気も必要。

テンプレート A：支配型（相手より上手いチーム向け）

局面やること担当

テンプレート B：カウンター型（相手より速い・守備的チーム向け）

局面やること担当
GKからロングパスでST or サイドへ。無理にビルドしないGK → ST/LM/RM
自陣5-2-0でブロック。相手の攻撃を止める全員

前線3対2 or 2対1。素早くゴール前ST + LM/RM

局面やること担当

🔄 状況別 攻め方の切り替え

状況推奨テンプレート理由
リードしているB（カウンター型）守備を固め、カウンターで2点目
ビハインドA（支配型）ボールを保持し、相手を引き出す
同点・前半C（バランス型）相手を見て柔軟に対応
相手が守備的A（支配型）引き出してから攻める
相手が攻撃的B（カウンター型）裏スペースを突く

🎯 セットプレー

コーナーキック（CK）攻撃

パターンA：ニアファー

  • 蹴る： LM or RM
  • ニア： ST（ヘディング or フリック）
  • ファー： CB（ヘディング）
  • 外： CM（2ndボール）

パターンB：ショートCK

  • CKをショートパス → 1vs1 or 2vs1を作る
  • 8人制はゴールまで近いので有効

フリーキック（FK）攻撃

直接FK

  • ゴールから18m以内 → シュート
  • 壁の上を越える or 壁の隙間を狙う

間接FK

  • LM/RMが蹴り、ST+CBがゴール前
  • 8人制は人数が少ない → 全員ゴール前に入ってもOK

ゴールキック

  • ショート： CBへ。ビルドアップ開始（支配型）
  • ロング： ST or サイドへ直接（カウンター型）
  • 8人制はGKのパス精度が試合を左右する

スローイン

  • 相手ゴール側 → ST+CMをゴール前に。ロングスロー
  • 自陣サイド → CB/CBへ。保持してビルド
  • 8人制はスローインの距離が長い → 武器にできる

🏃 練習メニュー

パス＆ムーブ（15分）

  • 3人三角パス → 8人制の基本
  • 1タッチ・2タッチの切替
  • 「パス → 走る → 受ける」の繰り返し

サイドオーバーラップ（15分）

  • LM+LBの2対1ドリル
  • オーバーラップのタイミング合わせ
  • クロス → STのヘディング/ボレー

3対2 カウンター（15分）

  • 中盤で奪取 → 3人で前線へ
  • 3秒ルールを徹底
  • ST+LM+RMの走り方を統一

5対5 ゲーム形式（20分）

  • 実際の3-3-1（GK除く）で対戦
  • テンプレートA/B/Cを交代で試す
  • 試合後に振り返り（5分）

試合前ミーティング（5分で確認）

  1. 今日のテンプレートは A / B / C のどれか？
  2. セットプレーの担当確認（CK/FK蹴り手、ニア/ファー）
  3. 守備のライン：ハイ / ミドル / ロー のどれか？
  4. STの動き：下がる？裏走る？両方？
  5. 声出し：GKとCBが最後方から指示
