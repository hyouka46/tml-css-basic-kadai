📋 小学生 8人制 3-3-1 とは

小学生サッカーでは、5・6年生（高学年）の公式戦・リーグ戦で GK + フィールド7人の8人制 がよく使われます。3-3-1はバランスが良く覚えやすい定番フォーメーションです。


プロ（Jリーグ）の考え方をそのまま使うのではなく、「パスを出す」「走る」「仲間を助ける」 という基本を3-3-1の形で身につけさせるのが小学生サッカーの目的です。勝つことより、サッカーが好きになること・全員がボールに触れること を大切にしましょう。

小学生 8人制の特徴

  • ピッチが狭い → 短いパスが効く（ドリブルばかりにしない）
  • 人数が少ない → 1人の空きが大きなチャンスになる
  • 全員が攻撃にも守備にも関わる → 「ボールを持ってない人も大切」
  • サイド（横）を使うとゴールに近づきやすい
  • 体力的にも無理のない試合時間（1本10〜15分 × 2本 など）

3-3-1の強み（小学生向け）

  • 中盤3人で「三角形」を作りやすい
  • 守るときはみんなで下がって人数をそろえやすい
  • DF3人で守備の土台が作れる（小学生に安心感）
  • FW1人に集中 → ゴール前に行く役割がはっきりする
  • ポジション名が覚えやすい（コーチの指示が伝わりやすい）

👦 小学生サッカーで大切なこと

学年別の目安

学年重点3-3-1の使い方
3〜4年生低学年 ボールに触れる・パス・ドリブル・楽しさ まずは「守る人」「攻める人」の大まかな役割だけ。細かい戦術は後回し
5年生高学年 ポジションの役割・パス＆走る・声を出す 3-3-1の形を意識。攻撃パターン1〜2個を練習で覚える
6年生高学年 チーム戦術・セットプレー・試合の読み このガイドの内容を本格的に使える。テンプレートA/B/Cを試合で使い分け

🎯 小学生に優先して教える5つのこと

  1. パスを出す — 近くの仲間へ。強すぎず、弱すぎず
  2. パスを出したら走る — ボールを持ってない時間こそチャンス
  3. 声を出す — 「こっち！」「マーク！」「上がれ！」
  4. ボールを奪ったら前を向く — すぐ攻撃に切り替える
  5. 味方を助ける — 近くにいる仲間の近くを守る・サポートする

⚠️ 小学生サッカーで避けたいこと

  • 1人にボールを集中させすぎる（全員が触れない）
  • 難しい専門用語ばかり使う（子どもが混乱する）
  • 試合中に長い説教（30秒以内の短い指示に）
  • 結果（勝ち負け）だけを追いすぎる
  • 同じ子をずっと同じポジションに固定する

8人制のルール（よく使われる目安）

  • ピッチ： 約40m × 25m（大会により異なる）
  • ゴール： 高さ約2m × 幅約5m
  • 人数： GK1 + フィールド7 = 8人
  • オフサイド： 多くの大会でなし（小学生は走り込みやすい！）
  • スローイン： 足を浮かせず、両手で頭の後ろから投げる
  • ゴールキック： 手で投げる or 足で蹴る（大会ルールを確認）
ポイント： オフサイドがないので、FW（ST）は積極的に相手ゴール前を走り回ってOK！

⚔️ 攻め方 — 小学生向け 3つの型

基本の流れ：「パス → 走る → シュート」

プロチーム（Jリーグ）も同じ流れです。小学生にはこの3ステップで教えましょう。

  1. 自陣（うちのゴール側） — キーパー・DFから近くの仲間へパス。無理に前に行かない
  2. 中盤（真ん中） — サイド（LM/RM）やセンター（CM）でボールをつなぐ。相手が寄せてきたら反対サイドへ
  3. 前（相手ゴール側） — ゴール前まで行ったらシュート or 仲間へパス。ゴール前に人数を送る
基本型

① パスでつなぐ攻撃

  • ドリブルよりパスを優先（小学生はドリブルばかりになりがち）
  • ボールを持っている人の近くに仲間が2人いる状態を作る
  • 相手が寄せてきたら反対サイドへ素早くパス
  • 焦らず、チャンスが来るまでボールを大切に
声かけ：「近くの人にパス！ 一人で行かないで！」
速攻型

② 奪ったらすぐ攻める

  • ボールを奪ったらすぐ前を向く
  • 3秒以内に前の仲間（ST・サイド）へパス
  • ST＋LM＋RMの3人で前に走る
  • 相手が戻る前にゴール前まで行く
声かけ：「取った！ 前見て！ 走れ！」
サイド型

③ 横から攻める

  • サイド（LM/RM）でボールを受ける
  • サイドの守備（LB/RB）が前に上がってサポート
  • ゴール前へセンターリング（横パス）を出す
  • STがゴール前で待ってシュート
声かけ：「サイド行け！ 前上がれ！ クロス出して！」

攻めるときのみんなの動き

ボールを持って前に行くとき、全員が少しずつ前に出ます。

  • LB/RB → サイドのラインまで前に上がる
  • LM/RM → サイドでボールをもらう or 前に走る
  • CM → ゴール前（ペナルティエリア前）で待つ
  • CB → 一番後ろに残る（相手の速攻対策）
  • ST → ゴール前 or 相手DFの前で待つ
声かけ：「ボール持ってる人の近くに行け！ 離れすぎないで！」

🛡️ 守り方 — 小学生向け

守るときの基本：「みんなで下がって、人数をそろえる」

8人制3-3-1で守るときは、DF3人 + MF2人 が下がって守り、ST1人が相手のボール持ちを見ます。小学生には「みんなでゴールを守ろう」と伝えましょう。

声かけ：「ボールより人！ 相手より人数多く守れ！」

守備 ①：一列にそろえる

  • DFとMFの距離を近く保つ（離れすぎない）
  • 縦（前後）のラインをそろえる → 裏へのパスを防ぐ
  • CBは一番後ろ。LB/RBは左右をカバー
  • 相手ST1人にはCB+CMで2人で守る
声かけ：「ラインそろえて！ 離れないで！」

守備 ②：ボールを奪うタイミング

  • 前から攻める： ST+CMが相手に寄せて奪う（元気なチーム向け）
  • 中盤で待つ： 中盤で待って、横パスを出した瞬間に奪う（基本）
  • ゴール前で固める： ゴール前に人数を集めて守る（リード中向け）
声かけ：「寄せろ！ 一緒に行け！ 取れ！」

守備 ③：奪ったらすぐ攻め

  • ボールを奪ったらすぐ前を向く
  • ST+LM+RMが前に走り始める
  • CMが最初のパスを出す
  • 3秒ルール： 3秒以内に前の仲間へパス！
声かけ：「取った！ 前！ 走れ走れ！」

守備 ④：セットプレー

  • FK（フリーキック）： 壁を2〜3人。残りはゴールを守る
  • CK（コーナーキック）： ゴール前に人数を集める。1人1人マーク
  • スローイン： 相手に近づきすぎない。ラインを保つ
  • ゴールキック： DFラインを上げてコンパクトに

🎯 試合で使える攻撃パターン（5選）

練習で何度もやって、試合で「決まってる動き」として使えるようにしましょう。5〜6年生向け。

パターン1サイド攻撃

サイドに出す → 前に上がる → クロス

覚え方： 「サイド → 上がれ → クロス」

  1. CM（センター）がボールを持ち、左サイドのLMへパス
  2. LMがサイドでボールを保持。同時にLB（左の守備）が前に上がる
  3. LMはLBへパス、または前にドリブル
  4. ゴール前へ横パス（クロス）。STがゴール前で待ってシュート！
声かけ：「左サイド！ 前上がれ！ クロス！ ゴール前行け！」
ポイント： LBが前に上がるタイミングが大事。LMがボールを持っている間にLBが走る。
パターン2中央突破

STが下がる → CM前進 → 裏へパス

覚え方： 「下がる → 前進 → 走れ」

  1. CBからCMへパス。STは下がって相手DFの前に出る
  2. STが相手DFの注意を引いた隙に、CMが前に進む
  3. STが一気に前（ゴール側）へ走る
  4. CMからSTへ前へのパス → シュート！
声かけ：「下がれ！ 前進！ 走れ！ パス出して！」
ポイント： STの「下がってから走る」動きがカギ。小学生でもオフサイドがないので積極的に走り込める。
パターン3速攻

奪った！ → 3人で前へ → ゴール

覚え方： 「取った！ 走れ！ ゴール！」

  1. 中盤でCMまたはLM/RMが相手からボールを奪う
  2. 奪った人はすぐ前を向いてパス（3秒以内！）
  3. ST＋LM＋RMの3人が前に走る
  4. 相手DFが2人しかいない → 3対2で有利！
  5. STへパス → STがLM or RMへ渡す → ゴール前でシュート
声かけ：「取った！ 前！ 走れ！ パス！ シュート！」
ポイント： ためらうと相手が戻ってくる。奪った瞬間がチャンス！
パターン4中央からシュート

サイドの内側 → 前進 → シュート

覚え方： 「内側入って → 前進 → シュート」

  1. LM/RMがサイドの少し内側でボールを受ける
  2. LB/RBがサイドのラインまで上がる
  3. LM/RMがゴール方向にドリブル
  4. ゴール前まで行ったらシュート or STへパス
声かけ：「内側入れ！ 前進！ シュート！」
ポイント： 8人制はゴールまで近い。前進してシュートする勇気を持とう。
パターン5サイドチェンジ

左に集める → 右へ大きくパス → 1対1

覚え方： 「左に集めて → 右へ！ 行け！」

  1. 左サイド（LM+LB）にボールを集める → 相手が左に寄せてくる
  2. CMまたはCBから右サイド（RM）へ大きくパス
  3. RMが相手DF1人と1対1
  4. RMが前にドリブル → ゴール前へクロス or シュート
  5. ST+CMがゴール前で待つ
声かけ：「右！ 右！ 行け！ 1対1！」
ポイント： 反対サイドに素早くパスを出す勇気が大事。RMがフリーになったらチャンス！

📝 攻め方テンプレート — 試合前に決めておく

試合前にコーチが子どもたちに「今日はこの攻め方で行こう」と伝えるための型です。

テンプレート A：パスで攻める（上手いチーム向け）

局面やること担当
GKからCBへ。相手ST1人なので余裕を持ってGK → CB
自陣ビルドLB/RBへ展開。三角形を作るCB → LB/RB → CM
中盤保持。相手が寄せたら反対サイドへCM → LM/RM
前線サイドオーバーラップ or インサイドカットLM/RM + LB/RB
決定打クロス or スルーパス → STST + CM

守り： 前からボールを奪りに行く。取ったらすぐ攻める

子どもへの説明：「今日はパスを大切にして、みんなでボールを回そう！」

テンプレート B：守って速攻（守備が強いチーム向け）

局面やること担当
GKからロングパスでST or サイドへ。無理にビルドしないGK → ST/LM/RM
自陣5-2-0でブロック。相手の攻撃を止める全員
奪取時3秒以内に前線へ。ST+LM+RM走り込みCM → ST/LM/RM
前線3対2 or 2対1。素早くゴール前ST + LM/RM
決定打STのシュート or 横パス → トゥータッチST → LM/RM

守り： ゴール前で人数を固める。取ったら3秒で前へ

子どもへの説明：「守って、取ったら走って前へ！ 3秒ルール！」

テンプレート C：バランス型（初めてのチーム・低学年向け）

局面やること担当
GKからCBへ。CBが状況を見てサイド or 中央GK → CB → CM/LB/RB
自陣無理しない。パスコースがなければキックCB/GK
中盤LM/RMに展開。1vs1を作るCM → LM/RM
前線サイドからクロス or 中央突破LM/RM + ST
決定打ゴール前に人数を送る（最低3人）ST + CM + LM/RM

守り： 中盤で一緒に守る。取ったら前へ

子どもへの説明：「パスを出して、出したら走る！ それだけでOK！」

🔄 状況別 攻め方の切り替え

状況推奨テンプレート理由
リードしているB（カウンター型）守備を固め、カウンターで2点目
ビハインドA（支配型）ボールを保持し、相手を引き出す
同点・前半C（バランス型）相手を見て柔軟に対応
相手が守備的A（支配型）引き出してから攻める
相手が攻撃的B（カウンター型）裏スペースを突く

📣 コーチの声かけ集 — そのまま使える

試合中・練習中にそのまま使える声かけです。短く、はっきり、元気よく！

攻撃の声かけ

  • 「パス！ パス！」— ドリブルばかりさせない
  • 「出したら走れ！」— パス＆ムーブの基本
  • 「広げろ！」— サイドに散らばる
  • 「前！ 前！」— 前に進む
  • 「シュート！」— チャンスなら迷わず蹴る
  • 「クロス！」— サイドからゴール前へ
  • 「1対1！ 行け！」— ドリブルチャンス
  • 「右！ / 左！」— サイドチェンジ

守備の声かけ

  • 「寄せろ！」— 相手に近づく
  • 「一緒に行け！」— 複数人でプレス
  • 「取れ！」— ボールを奪う
  • 「ライン！」— 一列にそろえる
  • 「マーク！」— 相手選手をマーク
  • 「下がれ！」— 守備位置に戻る
  • 「カバー！」— 味方の裏を守る
  • 「取った！ 前！」— 奪取後すぐ攻撃

全体の声かけ

  • 「声出せ！」— コミュニケーション
  • 「こっち！ こっち！」— パスを求める
  • 「ナイス！」— 良いプレーを褒める
  • 「次行こう！」— ミス後の切り替え
  • 「走れ！」— ボールを持っていなくても走る
  • 「見て！ 見て！」— 周りを見る
  • 「仲間！ 仲間！」— 味方を見る
  • 「楽しめ！」— 最後に忘れずに

ポジション別の声かけ

ポジ声かけ例
GK「上！ 上！」「右！」「左！」（指示）
CB「落ち着け！」「前出して！」
LB/RB「上がれ！」「戻れ！」
CM「前見て！」「サイド行け！」
LM/RM「行け！」「クロス！」「戻れ！」
ST「走れ！」「下がれ！」「シュート！」

⚠️ 声かけのコツ（コーチ向け）

  • 短く： 1文10文字以内が理想。「パス！ 走れ！」
  • 具体的に： 「頑張れ」より「前の人にパス！」
  • 否定的より肯定的： 「ダメ」より「次行こう！」
  • 名前を呼ぶ： 「田中、パス！」の方が伝わる
  • 試合中は30秒以内： 長い説明はハーフタイムに
  • 褒める： 良いプレーは必ず「ナイス！」

🎯 セットプレー

コーナーキック（CK）攻撃

パターンA：ニアファー

  • 蹴る： LM or RM
  • ニア： ST（ヘディング or フリック）
  • ファー： CB（ヘディング）
  • 外： CM（2ndボール）

パターンB：ショートCK

  • CKをショートパス → 1vs1 or 2vs1を作る
  • 8人制はゴールまで近いので有効

フリーキック（FK）攻撃

直接FK

  • ゴールから18m以内 → シュート
  • 壁の上を越える or 壁の隙間を狙う

間接FK

  • LM/RMが蹴り、ST+CBがゴール前
  • 8人制は人数が少ない → 全員ゴール前に入ってもOK

ゴールキック

  • ショート： CBへ。ビルドアップ開始（支配型）
  • ロング： ST or サイドへ直接（カウンター型）
  • 8人制はGKのパス精度が試合を左右する

スローイン

  • 相手ゴール側 → ST+CMをゴール前に。ロングスロー
  • 自陣サイド → CB/CBへ。保持してビルド
  • 8人制はスローインの距離が長い → 武器にできる

🏃 小学生向け 練習メニュー

練習の基本ルール（コーチ向け）

  • 1つの練習は15分以内 — 小学生の集中力に合わせる
  • ボール触る時間を最大化 — 列に並んで待たせない
  • ゲーム形式を多めに — 楽しさが一番
  • 全員同じポジションを経験 — FWばかりやGKばかりにしない
  • 最後に必ず試合形式 — 練習の成果を試す時間

① パス＆走る（10分）

  • 3人1組で三角パス
  • 「パス → 走る → 受ける」を繰り返す
  • 1タッチパスに挑戦（慣れたら）
  • 声かけ：「出したら走れ！」

② サイド攻撃（10分）

  • LM+LBの2人でサイドを攻める
  • LBが前に上がるタイミング合わせ
  • ゴール前へクロス → STがシュート
  • 声かけ：「前上がれ！ クロス！」

③ 3対2 速攻（10分）

  • 中盤でボールを置いて、奪いに行く
  • 奪ったら3人で前へ走る
  • 3秒以内にゴール前まで
  • 声かけ：「取った！ 走れ！」

④ ミニゲーム 4対4（15分）

  • 小さいコートで4対4（GK除く）
  • 今日の攻撃パターン1つを意識
  • 得点したら「どうやって点取った？」と聞く
  • 声かけ：「ナイス！ 次も行こう！」

⑤ 8人制ゲーム（15分）

  • 実際の3-3-1で対戦
  • テンプレートA/B/Cを交代で試す
  • 1本10分 × 2本
  • ハーフタイムに1分だけ振り返り

⑥ シュート練習（10分）

  • ゴール前からシュート（近距離から）
  • 両足で蹴れるように（利き足だけに偏らない）
  • 「迷わず蹴る」ことを褒める
  • 声かけ：「シュート！ ナイス！」

試合前ミーティング（3分・子ども向け）

  1. 「今日の作戦は A / B / C のどれか？」（1つだけ）
  2. 「攻撃パターンは ○番 を使おう！」（1つだけ）
  3. 「CK/FKは 名前 が蹴るよ」
  4. 「守るときは みんなで下がって 人数をそろえよう」
  5. 「声を出して、楽しもう！」
コツ： 指示は3つ以内。多すぎると子どもは覚えられない。

試合後の振り返り（3分・子ども向け）

  1. 「今日 良かったこと は？」（子どもに聞く）
  2. 「ナイスプレー 賞」（1人ずつ具体的に褒める）
  3. 「次は ここを意識 しよう」（1つだけ改善点）
  4. 「お疲れさま！ サッカー楽しかった？」
