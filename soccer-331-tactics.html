2ポジションごとの仕事

強いチームは、個人技以前に「誰が何をするか」が共有されています。

トップ（FW） 受け所の確保、最終ライン背後への抜け、相手CBの引きつけ。失ったあとは第一プレッシャーの起点。
左右MF 幅を作る／内側へ切り込む／クロス・カットイン。守備時はハーフウェイ付近まで戻り、外側のコースを閉じる。
中MF（アンカー） ビルドアップのハブ。左右・前方へ配球し、奪われた瞬間いちばん早く回収位置へ戻る。
DF3 ラインを崩さず横スライド。飛び出しはCBが判断。SBは攻撃参加時も内側にカバーを残す。
GK 最終ラインの管理。「右」「カバー」「ライン上げ」など、声でチームの距離感を整える。
判断の基準は「ボールを持っている味方の近くに、常に2つの受け口があるか」。なければ動く。

3攻め方テンプレート（4型）

試合中に迷ったら、この4つから選ぶ。状況に応じて切り替えるだけで、攻撃の再現性が上がります。

形：ボール保持者＋近くの2人で三角形。1パスしたら、受け手以外が次の受け所へ動く。

  2. トップが少し下がって壁になる
  3. ワンタッチで返し、右MFまたはアンカーが最終ライン裏へ出す
  4. 逆サイドMFがゴール前へ走り込む（こぼれ・カットバック用）
D

奪ってからのカウンター

いつ使う：中盤〜自陣で奪った直後。相手の戻りが遅い局面。

  • 奪った瞬間、前を向ける選手へ最短パス
  • トップは縦へ走る（受けに下がらない）
  • ボールサイドのMFがサポート、逆サイドはゴール前へ斜走
  • 目安：3本以内でシュートゾーンへ。つながらなければ無理に持ち込まず保持へ切替
注意：カウンター失敗後に全員が押し上げたまま残ると失点につながる。アンカーとCBは必ず回収位置を残す。

4実際の攻撃の進め方

テンプレートを試合で使うための「流れ」です。キックオフからゴール前まで、同じ順番で考えます。

フェーズ1｜自分たちのボールにする

キックオフ／再開

  • 最初の2本は安全に（サイドMF or アンカーへ）
  • 相手プレスが強いなら、すぐ幅を使いスペースを作る

GK・DFからの配球

  • 第一選択：足元のSB／アンカー
  • 詰まれば反対サイドへスイッチ
  • ロングは「トップの競り＋こぼれ回収」までセット

フェーズ2｜前進する（どこを攻めるか決める）

ボールを持ったら、次の優先順位で見る。

  1. 前が空いているか → 空いていれば縦パス／ドリブルでテンプレC or D
  2. 中央が詰まっているか → 詰まっていればテンプレB（外へ）
  3. どちらも厳しいか → テンプレAでいったんリセット（下げて作り直し）
個人判断の目安：ボール保持は最大3タッチ。4タッチ目に入る前に「出す／運ぶ／戻す」を決める。

フェーズ3｜フィニッシュ（ゴール前の型）

① カットインシュート

サイドMFが内側へ切り込み、遠めからでも枠内へ。逆足ならカットバックを優先。

② クロス → 中

トップはニア、逆サイドMFはファー。アンカーはペナ外でセカンドボール。

③ カットバック

ゴールライン際まで運んだら、戻しパス。走り込むのは中MF or 逆サイド。

具体シーケンス例（右サイド起点）

  1. CB → 右SBへ横パス
  2. 右SBが押し上げ、右MFがさらに外へ広がる（幅を作る）
  3. アンカーが右ハーフスペースへ寄り、三角形を作る
  4. 右MFが受けて前を向く → トップが斜めに動いて受け所を作る
  5. 出せるなら最終ライン裏へ。無理なら一度アンカーへ戻し、逆サイドへスイッチ
  6. 逆サイド到達後、左MFがクロス or カットイン。ファーに右MFが走り込む

左起点も同じ手順の鏡写し。左右どちらからでも同じ「型」で攻められるようにしておく。

よくある失敗と修正

やりがち

  • FWだけが前に残り、孤立する
  • サイドで止まって横パスだけ繰り返す
  • 奪われたあと、前がかりのまま全員が前に残る

修正

  • トップは「受ける／引っ張る／裏へ」を交互に
  • 外で止まったら、中への1本かスイッチを選ぶ
  • 攻撃参加は最大5人。アンカーとCBは残す

5守り方の原則

攻撃の型を増やすほど、守備の共通言語が重要になります。基本は2つだけです。

守り① コンパクトを保つ

DF3とMF3の距離を開きすぎない。トップも相手最終ラインに張り付きすぎず、奪われたあとに即プレッシャーできる位置を取る。

守り② ボールサイドへ寄せる

  • 1人目：ボール保持者へアプローチ
  • 2人目：パスコース（特に内側）を切る
  • 3人目：ゴール前と逆サイドのカバー
やってはいけないこと：1人が追いかけるだけで、ライン全体が動かないこと。寄せは「個人」ではなく「ブロック」で行う。

6試合で共有する原則

1. ボールを失わない優先順位

難しい縦パスより、確実な接続。失ったら5秒以内に回収を試みる。

2. 声は最速のパス

「もらえる」「スイッチ」「残して」など、短い合図をチームで統一する。

3. 空いた場所へ入る

誰かが動いたら、空いたレーンを埋める。ポジショナルプレーの最小単位。

4. 人数をそろえて動く

攻守とも「孤軍」を作らない。前に出る人数と残る人数をセットで決める。

★試合前チェック（短く）

  • 今日の主攻は A / B / C / D のどれか（第1候補と第2候補を決める）
  • 右起点・左起点のシーケンスを1本ずつ確認
  • 奪われたあとの残る2人（アンカー＋CB）を確認
  • フィニッシュは「カットイン／クロス／カットバック」のどれを優先するか
